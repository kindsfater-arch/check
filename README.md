# Сканер чеков и справочник MCC

Страница: https://kindsfater-arch.github.io/check/ · Репозиторий: https://github.com/kindsfater-arch/check

Кнопка **«Получить описание MCC»** открывает поле для четырёх цифр. После ввода кода и нажатия **«Показать описание»** страница показывает деятельность торговой точки, ссылку на источник и дату получения справочника. Начальный ноль сохраняется: например, `0742` — ветеринарные услуги. Если код отсутствует в справочнике НСПК, форма сообщает об этом.

Встроены 923 описания из публичного калькулятора на странице [НСПК / СБП](https://sbp.nspk.ru/business/accepting-payments#business-commission-726), полученные 31.10.2026. Поиск выполняется в браузере без Gemini и дополнительных сетевых запросов. После загрузки страницы этот сценарий работает и без интернета. Это копия справочника на указанную дату; автоматическое обновление не выполняется.

Веб-форма распознаёт фото чека, позволяет исправить поля и сохраняет данные в Google Sheets. Кнопка **«Подобрать MCC по описанию»** открывает отдельную форму: пользователь описывает деятельность торговой точки, а Gemini предлагает номер MCC, описание категории и краткое объяснение выбора. Фото для подбора MCC не требуется.

Если описание недостаточно конкретно, форма показывает уточняющий вопрос. Пользователь дополняет описание и повторно нажимает **«Предложить MCC»**. Максимальная длина описания — 3000 символов.

Подбор добавлен только в веб-форму. Рекомендация отображается текстом; она не записывается в строку чека. Окончательное назначение MCC согласуется с банком-эквайером.

## Как устроен проект

- `index.html` — самостоятельная веб-страница для GitHub Pages или другого статического хостинга.
- `data/mcc-catalog.json` — описания MCC, источник, дата получения и контрольная сумма исходного модуля НСПК; копия данных встроена в `index.html`.
- `scripts/update-mcc-catalog.cjs` — импорт и синхронизация справочника с самостоятельной страницей.
- `Code.gs` — обработчик Google Apps Script: `recognize_receipt`, `save_receipt`, `suggest_mcc` и существующий Telegram webhook.
- `GeminiService.gs` — распознавание фото и подбор MCC через ту же модель Gemini 2.5 Flash.
- Остальные `.gs` — существующие сервисы Telegram-бота, состояния и записи в таблицу.
- `Config.example.gs` — образец серверной конфигурации. Рабочий `Config.gs` не публикуется.
- `appsscript.json` — манифест Apps Script.

Браузер обращается к Apps Script, сервер вызывает Gemini. API-ключ остаётся в серверной конфигурации. Для совместимости с Apps Script запросы страницы используют `Content-Type: text/plain;charset=utf-8`.

## Обновление существующего проекта

Для добавления поиска **описания по коду** достаточно обновить `index.html` на GitHub Pages. Переопубликовывать Apps Script для этой функции не требуется. Остальные файлы проекта, справочник и проверки хранятся в том же репозитории; рабочий `Config.gs` исключён из публикации.

Для обновления серверной части, если она менялась:

1. В действующем проекте Apps Script замените содержимое `Code.gs` и `GeminiService.gs` файлами из этого репозитория. Если файл называется `code`, обновите его, не создавая второй обработчик.
2. Сохраните существующий серверный файл `config` / `Config.gs` с рабочими ключами и идентификаторами. `Config.example.gs` загружать поверх него не нужно.
3. В **Deploy → Manage deployments → Edit** выберите **New version** и обновите существующую публикацию. Так её URL останется прежним.
4. Обновите `index.html` на хостинге. Значение `SAVE_ENDPOINT_URL` должно указывать на URL `/exec` этой публикации.

При развёртывании с нуля добавьте серверные `.gs` и манифест в Apps Script, создайте конфигурацию по образцу `Config.example.gs` и опубликуйте Web App. Доступ и выполнение должны соответствовать настройкам существующего проекта.

## Проверка

Нужен Node.js 22.22.2+, 24.15.0+ или 26+ (требование jsdom 30).

```sh
npm ci
npm test
```

Тесты проверяют ввод и результат обеих форм, ведущий ноль в коде, неизвестный код, поиск без сети, соответствие встроенного справочника JSON-файлу, повторные запросы, ошибки API, уточнение описания, безопасный вывод текста и прежние маршруты распознавания и сохранения чека. Запросы к Gemini и запись в таблицу в этих тестах заменены тестовыми ответами.

### Обновление справочника

Скачайте публичный JS-модуль калькулятора MCC со страницы НСПК, содержащий JSON-массив с полями `Code` и `Text`, затем выполните:

```sh
node scripts/update-mcc-catalog.cjs /path/to/bundle.js https://sbp.nspk.ru/_nuxt/имя-модуля.js
npm test
```

Точный URL использованного модуля записан в `source_bundle` файла `data/mcc-catalog.json`; при обновлении сайта НСПК имя модуля может измениться. Импорт извлекает только строку с JSON, проверяет коды и дубликаты и не запускает код загруженного модуля. Поля тарифов не импортируются.

После ручного изменения JSON повторно встроить его в страницу можно командой `npm run mcc:sync`. Публикуйте обновлённые `index.html` и `data/mcc-catalog.json` вместе.

Для двух реальных пробных запросов используйте локальный приватный `Config.gs` с действующим ключом:

```sh
npm run test:live
```

Другой приватный конфигурационный файл можно указать через переменную `MCC_CONFIG_PATH`. Проверка не выводит ключ. Не добавляйте рабочую конфигурацию в репозиторий.
